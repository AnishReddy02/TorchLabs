# Bench investor deck

Open `BenchDeck.html` in a browser. It follows YC's seed-deck sequence: company/tagline, vision, problem, customer, solution/product, market, landscape, progress, business model, team, and fundraising. Navigate with the arrow keys, Page Up/Page Down, or the on-screen controls.

`technical-appendix.html` preserves the longer original deck for architecture and product-detail follow-up questions.

To create a PDF, open the deck in Chrome, choose **Print**, set **Layout** to landscape, enable **Background graphics**, set margins to **None**, and save as PDF. The print stylesheet produces 16:9 pages.

Before sending externally, replace the design-partner and fundraising language with the actual round size, use of funds, founder story, customer evidence, and contact information. The deck intentionally contains no invented traction, revenue, customer logos, or unsupported market-size figures.
